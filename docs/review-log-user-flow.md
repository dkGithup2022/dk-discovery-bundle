### 범위 밖이라 남긴 것

- discovery-sitemap 스킬에는 유저 흐름 단계에서 넘어온 추가 후보를 입력으로 받는 인자나 절차가 없고, 기존 sitemap.md가 있을 때의 처리(덮어쓰기 금지, 이어서 하기)도 없다. "discovery-sitemap 재실행"으로 정한 후보가 재실행 때 반영된다는 보장이 없고, 재실행으로 페이지 번호가 다시 매겨지면 이미 그린 흐름의 번호가 어긋날 수 있다. 사이트맵 스킬 쪽에 추가 후보 입력과 기존 번호 유지 규칙이 필요하다.
- sitemap-guide.md 이동 표 예시에서 X1을 "X1 로그인"으로 적었는데, 같은 문서의 트리 예시와 이 스킬 예시는 "X1 로그인·가입"이다. 완성 조건 "노드 이름이 sitemap.md의 페이지 이름과 같다"를 예시로 설명할 때 헷갈릴 수 있다.
- sitemap-guide.md "구성 요소"와 이동 표 설명에는 알림·외부 링크로 들어오는 이동을 "들어오는 곳"에 어떻게 적는지가 없다. 이 스킬은 "알림 → P10"처럼 적는다고 정했으니, 사이트맵 가이드에도 같은 표기를 넣어야 두 단계가 맞물린다.
- handoff.json의 `sitemap_candidates.applied_by`는 값 하나만 받는다. 재실행 대기 뒤 재개해 sitemap.md 갱신까지 함께 쓴 경우를 어떻게 적을지는 와이어프레임 단계가 이 값을 쓰는지 정해진 뒤에 정한다.

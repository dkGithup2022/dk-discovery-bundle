# design-references — 실행 예시

실행 대상: 크루 매거진 커뮤니티 앱 (원본: `try_project_discovery_2/planner/260918-1754-crew-magazine-community-app/design_handoff/references/`, 2026-09-20 — 캡처 커밋 `3e5b7ab`·`1200a0b`·`c2d6022`, 선별 `23e0742`, 의미 정리 `05d6a4f`)

## 호출

```
/dk-discovery-bundle:design-references Mood: ui-spec/ui-spec.md
```

원래 스킬 이름은 `cc_design_handoff:v1-design-references`이다. `Mood:`를 주지 않으면 UI 기획 문서의 "전역 분위기" 절을 기준으로 삼고, 그것도 없으면 유저에게 묻는다. 유저가 미리 넣고 싶은 사이트가 있으면 `Add:`로 넘긴다.

## Input

- `ui-spec/ui-spec.md`의 "전역 분위기" 절: 후보를 고르는 기준이다. 이 run에서는 "동네 독립잡지의 톤. 사진과 글이 주인공이고 UI는 조용한 배경"으로 시작하는 문단이었다.
- `capture-guide.md` (스킬에 들어 있는 캡처 규칙): 줌아웃해서 한 컷에 담기, 쿠키 배너 거부, 컷마다 URL 기록, playwright 부산물 정리.

여기서 모으는 것은 경쟁사가 아니라 닮고 싶은 톤이다. 그래서 커머스(29CM·쿠팡), 숙박(Airbnb), 금융(토스)처럼 도메인이 다른 서비스도 후보에 들어갔다.

## 유저와 주고받은 것

**후보 확정 (캡처 전)**: 후보 15곳을 5곳씩 세 번에 나눠 캡처했다(커밋 3개). 각 사이트의 shots.md 맨 위에 "우리 분위기와 닿는 점"이 한 줄씩 적혀 있고, 이것이 후보를 넣은 이유다. 몇 가지 예시는 다음과 같다.

> - 29CM: 콘텐츠 퍼스트 커머스의 교과서 — 큰 사진과 에디토리얼 카피가 먼저, 상품은 그 다음.
> - 당근: 지역·이웃의 생활 글이 그대로 콘텐츠가 되는 동네 감성 — … "동네 독립잡지"의 정서적 바탕과 닿는다.
> - Luma: 이벤트 페이지를 초대장처럼 만드는 절제된 카드 디자인 — … 모임 이벤트 화면의 직접 참조.
> - 쿠팡: 닮고 싶은 톤이 아니라 대비 기준 — 가격·뱃지·타이머가 전면에 나오는 고밀도 상품 진열.

**선별 (캡처 후)**: 15곳 중 디자인 도구에 보낼 5곳을 골랐다. 쿠팡은 캡처할 때 "피하려는 분위기의 예"로 기록됐지만, 선별에서는 사용성만 참고하는 레퍼런스로 역할이 바뀌어 5곳에 들어갔다. 유저가 남긴 원문은 다음과 같다.

> 쿠팡 — "사용성이 좋았어서 그래. 기획적 관계는 없지만"

### 캡처 기록 한 곳 (ohou/shots.md)

이미지는 여기에 옮기지 않았다. 오늘의집은 홈 피드, 집들이 상세, 집들이 목록 세 장을 찍었고 shots.md는 다음과 같다.

> 캡처일: 2026-09-20 · 최종 URL: https://ohou.se/ (집들이 콘텐츠는 contents.ohou.se로 리다이렉트)
> 우리 분위기와 닿는 점: 유저의 실제 공간 사진·이야기(집들이)가 콘텐츠가 되어 커머스를 끄는 구조 — "활동 기록이 읽을거리가 되고, 읽다가 팔로우한다"는 우리 동선과 같은 뼈대.
>
> | 파일 | 화면 | URL | 비고 |
> |------|------|-----|------|
> | landing.png | 첫 화면 (홈 피드) | https://ohou.se/ | 집들이 히어로 + 사진 추천 + 추천 집들이 카드 |
> | detail.png | 집들이 상세 (콘텐츠 상세) | https://contents.ohou.se/projects/203535 | 제목·작성자·팔로우 버튼·태그 메타 → 본문 사진, 우측 플로팅 좋아요/스크랩 |

다른 곳도 같은 형식이다. Medium은 로그아웃 히어로, Creativity 태그 피드, 아티클 본문을 찍었다. Meetup은 이벤트 피드, 이벤트 상세, 그룹 홈을 찍었다. 쿠팡은 메인 홈, 골드박스 특가 리스트, 상품 상세를 찍었다.

### 따라할 것과 따라하지 않을 것 (reference-notes.md, 쿠팡 부분)

> ## 쿠팡 (coupang/) — 사용성만
>
> **따라하고 싶은 것:**
> - 리스트에서 스캔이 빠른 정보 위계 — 핵심 정보가 눈에 먼저 들어오는 배치
> - 클릭하기 전에 판단에 필요한 정보가 카드 안에 다 있는 것
> - 탐색 → 상세 → 행동으로 이어지는 동선에 마찰이 없는 것
>
> **따라하지 않을 것:** 시각 밀도와 프로모션 톤 — 우리 분위기 선언과 정반대이므로
> 절대 따르지 않는다. 이 레퍼런스는 "느낌"이 아니라 "동선"을 보는 자료다.

나머지 네 곳도 같은 형식이다. 예를 들어 Medium은 "텍스트 일변도의 미니멀"을 따르지 않는다고 적었다. 이 서비스에서는 모임의 분위기를 사진이 전달하기 때문에 사진 비중이 커야 한다는 이유다.

## 참고

- 15곳 모두 최소 1장은 찍었고 완전히 막힌 곳은 없었다. Strava는 활동 피드가 로그인 뒤에 있어서, Pinterest는 닫기 버튼 없는 로그인 모달이 떠서 일부만 찍혔다. Pinterest에서는 모달을 DOM에서 지우는 방법도 시도했는데, 앱 전체가 같이 지워져 빈 화면이 됐다. 닫기 버튼이 없으면 차단으로 기록하고 넘어가는 편이 낫다(trial-notes.md).
- 15곳 중 9곳에서 리다이렉트가 일어나 처음 입력한 URL과 실제로 렌더된 URL이 달랐다. 그래서 shots.md에 컷마다 최종 URL을 적는다.
- trial-notes.md에 적힌 마찰점은 다음과 같다. 이 환경에서는 Bash의 `sleep`이 막혀 있어 `browser_wait_for`로 대신 기다렸다. 상세 페이지 URL은 `.playwright-mcp/*.yml` 스냅샷 파일을 grep해서 찾았다. 토스·Strava·Medium·Luma처럼 첫 화면이 마케팅 히어로인 사이트는 첫 화면에서 얻는 톤 정보가 적었다. 그래서 콘텐츠 피드를 대표 화면으로 먼저 찍으라는 안내가 캡처 가이드에 있으면 좋겠다고 적었다.

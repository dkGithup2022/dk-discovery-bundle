## 흐름별 그림

### F1 작업 사례를 보고 의뢰 등록하기
- 누가: 개발자를 찾는 예비 창업자
- 시작: 홈에서 무엇을 하는 개발자인지 본다
- 목표: 의뢰가 접수되었다
- 다루는 기능: 1, 2, 3

```mermaid
flowchart LR
    A0((맡길 개발자를 찾고 있다))
    A1[P1 홈]
    A2[/작업 사례 보기를 누른다 P1-2/]
    A3[P2 작업 사례]
    A4[/"카테고리를 고른다 P2-3 (선택)"/]
    A5[/작업 카드를 누른다 P2-4/]
    A6[P3 작업 상세]
    A7{맡겨도 되겠다고 판단했는가?}
    A8[/다른 작업을 누른다 P3-6/]
    A9[/프로젝트 등록하기를 누른다 P3-5/]
    A10[P4 의뢰 등록]
    A11[/단계마다 아는 만큼 입력한다 P4-4/]
    A12{필수 항목을 채웠는가?}
    A13([입력 오류 표시])
    A14[/의뢰 등록을 누른다 P4-5/]
    A15[X1 의뢰 접수 완료]
    A16((의뢰가 접수되었다))
    N1["조건: 필수는 프로젝트 이름과 연락처 (나머지는 비워도 된다)"]:::note
    A0 --> A1 --> A2 --> A3 --> A4 --> A5 --> A6 --> A7
    A7 -- 아니오 --> A8 --> A6
    A7 -- 예 --> A9 --> A10 --> A11 --> A12
    A11 -.- N1
    A12 -- 아니오 · 실패 --> A13 --> A11
    A12 -- 예 --> A14 --> A15 --> A16
    classDef note fill:#f4f4f4,stroke:#bbb,color:#777,stroke-dasharray:3 3
```

- 이 흐름에서 나온 화면 상태: P4 오류
- 이 흐름에서 나온 사이트맵 추가 후보: 없음

### F2 간단 상담 남기기
- 누가: 개발자를 찾는 예비 창업자
- 시작: 정식 의뢰 전에 짧게 묻고 싶다
- 목표: 질문을 남겼다
- 다루는 기능: 4

```mermaid
flowchart LR
    A0((이 기능을 만들 수 있는지 먼저 묻고 싶다))
    A1[P1 홈]
    A2[/간단히 문의하기를 누른다 P1-2/]
    A3[M1 간단 상담]
    A4[/이름·연락 방법·질문을 쓴다 M1-2/]
    A5{필수 항목을 채웠는가?}
    A6([입력 오류 표시])
    A7[/보내기를 누른다 M1-3/]
    A8([보내기 완료])
    A9((질문을 남겼다))
    N1[답변은 적은 연락 방법으로 간다]:::note
    A0 --> A1 --> A2 --> A3 --> A4 --> A5
    A5 -- 아니오 · 실패 --> A6 --> A4
    A5 -- 예 --> A7 --> A8 --> A9
    A8 -.- N1
    classDef note fill:#f4f4f4,stroke:#bbb,color:#777,stroke-dasharray:3 3
```

- 이 흐름에서 나온 화면 상태: M1 오류
- 이 흐름에서 나온 사이트맵 추가 후보: 없음
